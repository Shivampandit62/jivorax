How to use this validator

  1. Paste your JSON — an API response, a settings file, a config snippet, anything.
  2. Press Validate (or just wait — the status updates as you pause typing).
  3. Fix any error using the line, column and caret snippet in the red panel.
  4. Read the summary when it's valid: root type, key and array counts, value types, nesting depth and byte size. Copy the report for your notes.

Useful information

JSON has no comments, no trailing commas and no single quotes — rules that feel fussy until you're staring at a response that won't parse. A validator that points at the exact character saves the guesswork.

What gets checked

The text is parsed against the JSON grammar (RFC 8259): every key double-quoted, strings escaped correctly, numbers in legal form, brackets balanced, and only true, false and null as literals. One violation and parsing stops with a location.

Reading the structure summary

For valid JSON you get a quick anatomy: the root type (object, array or scalar), how many keys and arrays it contains, the count of each value type, the maximum nesting depth and the size in bytes. It's a fast way to spot, say, a payload that's 90% strings or nests 12 levels deep.

Validating vs formatting

Validation tells you whether it's correct; formatting makes it readable. Once your JSON passes, jump to the JSON Formatter to indent it — or minify it for shipping.

Privacy: everything uses your browser's built-in parser, so secrets and internal data in payloads never leave the machine.

Frequently asked questions

What does this JSON validator check?

It parses your text against the JSON grammar (RFC 8259): quoted keys, valid string escapes, numbers without trailing commas, correct brackets and braces, and the literals true, false and null.

What does the structure summary show?

Once the JSON is valid you get the root type, total object keys, array count, value counts by type, maximum nesting depth and the size in bytes — handy for checking API payloads at a glance.

How do I fix a reported error?

The error panel gives the line, column and a snippet with a caret pointing at the offending character. The usual culprits are a missing quote, a trailing comma, or an unquoted object key.

What is the difference from the JSON Formatter?

The Validator focuses on checking and describing your JSON — validity, errors and structure. The Formatter rewrites it with indentation or minifies it. Both share the same friendly error reporting.

Is my JSON uploaded anywhere?

No. Parsing runs entirely in your browser with the built-in JSON parser — your data is never sent to a server or stored by Jivora.
