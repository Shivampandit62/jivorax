How to use this password generator

  1. Set the length. Drag the slider — longer passwords are dramatically stronger, so 16 characters is a good default and 20+ is better for important accounts.
  2. Choose the character sets. Toggle uppercase, lowercase, numbers and symbols. Turn on “Avoid similar characters” if you need to read the password aloud.
  3. Generate. A fresh password appears instantly, along with a strength rating and an entropy estimate in bits.
  4. Copy it. Press Copy, then paste it straight into your password manager or sign-up form. Come back any time for a new one.

Useful information

A good password is long and unpredictable. Length is the single biggest factor: every extra character multiplies the number of combinations an attacker has to try, while clever substitutions like “p@ssw0rd” barely help against modern cracking tools.

How the randomness works

This generator uses crypto.getRandomValues(), the same secure random source your browser uses for session tokens. Each character is drawn fairly from the selected pools — no weak Math.random() and no predictable patterns.

Understanding the strength meter

The meter shows entropy in bits: length × log2(pool size). Under 30 bits is weak, 30–49 is fair, 50–69 is strong, and 70 or more is excellent. A 16-character password using all four character sets lands well into the “excellent” range.

One password, one account

Because generating a new password is free here, avoid reusing them. Give every account its own random password and keep them in a trusted password manager — that way one leak never unlocks the rest of your life online.

Frequently asked questions

How strong is the generated password?

Strength is measured in entropy bits: length × log2(number of possible characters). A 16-character password drawn from letters, numbers and symbols works out at roughly 100 bits — far beyond what brute force can realistically crack.

Are generated passwords stored or sent anywhere?

No. Passwords are created in your browser using the cryptographically secure crypto.getRandomValues() function and are never sent to a server, logged or saved by Jivora.

What password length should I use?

14 characters or more is a good baseline for most accounts, and 16 is the default here. Use 20+ for high-value accounts like email or banking — length matters more than clever substitutions.

What does “avoid similar characters” do?

It removes ambiguous characters such as i, l, 1, L, o, 0 and O so the password is easier to read out loud or retype without mistakes.

How do I copy the password?

Press the Copy button next to the password and it lands on your clipboard instantly. Paste it straight into your password manager or the signup form.
