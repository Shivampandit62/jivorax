Useful information

A QR code (Quick Response code) is a two-dimensional pattern that stores text in a machine-readable form. Any smartphone camera can read it in a second — no special app required.

What gets encoded

The type you choose simply controls the prefix: URL codes start with https:// so scanners open the page directly, Phone codes use tel: so tapping the scan result dials the number, and Email codes use mailto: to open a fresh draft. Plain Text is shown exactly as you typed it.

Designing codes people can scan

Keep the quiet zone (the white border around the code) intact, don't stretch the image, and place it where cameras can focus — dark code on a light background scans best. Larger print means longer scanning distance.

Reliability

This generator uses standard error correction, so the code still scans even if part of it is slightly obscured or damaged. Shorter content means bigger, more forgiving patterns — favour a link over a paragraph when you can.

Frequently asked questions

What can I put in a QR code?

Almost any short text: a website link, a message, a phone number that dials when scanned, or an email address that opens a new draft. Pick the matching type above and the correct format is added for you.

Is this QR code generator free?

Yes — completely free with no signup, no watermark and no limit on how many codes you create.

Do QR codes expire?

No. A QR code is just encoded text, so it keeps working forever. If you point it at your own link and later change where that link goes, the code itself stays valid.

Is my content uploaded anywhere?

No. The code is generated directly in your browser and the PNG you download never touches a server. Nothing you type is stored or transmitted by Jivora.

Why can't I fit a very long text?

QR codes have a practical capacity limit. This generator supports up to roughly 210 characters at high reliability — for longer content, host it on a webpage and put the link in the code instead.
