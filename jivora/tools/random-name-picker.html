How to use this picker

  1. Paste your names — one per line, from a spreadsheet, a class list or a chat export. Blank lines are ignored.
  2. Choose how many to draw. One name for a single winner, more when you also need runners-up — up to twenty at a time.
  3. Decide on repeats. Leave no-repeat on so everyone is picked once before the pool starts over, or turn it off to draw freely from the raw list.
  4. Press Pick a name and copy the result if you want to share it. Reset clears the pool and the counters.

Useful information

A random draw settles arguments that would otherwise eat a meeting: who presents, who goes first, who gets the last slice. Writing names on slips of paper works, but it is slow, it is easy to cheat by accident, and half the room cannot see the result.

How the draw stays fair

The picker picks an index with your browser's cryptographic random source and rejects biased values before they are used, so every name in the list has exactly the same chance — even with ten thousand entries. Nothing about the order you typed them in matters.

Repeats on or off

No repeats on treats each name as one seat: a name typed twice is still one entry, and once everyone has been picked the pool refills automatically. No repeats off draws from the raw lines instead, so a name that appears twice genuinely has twice the chance — useful for weighted giveaways, accidental for roll calls.

Built for the room, not the spreadsheet

There is nothing to configure and no list to import: paste, draw, read the name out loud. The status line keeps count of what is left in the pool, so you always know whether the next draw is a fresh name or a repeat.

Privacy: the list lives only in this tab. Refresh and it is gone — no upload, no history, no account.

Frequently asked questions

How does the random name picker work?

Paste your names, one per line, and press Pick a name. The draw uses your browser's built-in random generator, so every name has the same chance — and the list never leaves the page.

Can it draw more than one name at a time?

Yes. Set how many names to draw — anywhere from 1 to 20 — and they are returned together, which is handy when you need a winner plus runners-up.

What does the no-repeat option do?

With no repeats on, each name is drawn once before the pool starts over, and a name typed twice counts as a single entry. Turn it off and every line counts separately, duplicates included.

Is the draw actually fair?

Yes. The picker uses the browser's cryptographic random source with unbiased index selection, so no name is favoured and long lists are just as random as short ones.

Are my names stored or uploaded?

No. The list stays in this tab and disappears the moment you refresh or close the page — nothing is saved, logged or sent anywhere.
